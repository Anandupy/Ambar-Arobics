# Antriksh Antigravity Yoga Studio Website

This is a professional, single-page responsive website for "Antriksh Antigravity Yoga Studio" located in Kandivali West, Mumbai.

## Features
- **Modern Design**: Purple-blue gradient theme with smooth animations.
- **Mobile-First**: Fully responsive across mobile, tablet, and desktop.
- **Posture Gallery**: 16 detailed yoga postures with filtering functionality.
- **Modal System**: Detailed view for each yoga posture.
- **Classes & Pricing**: Responsive pricing table with WhatsApp integration.
- **Contact Form**: Validated contact form with success feedback.
- **SEO Optimized**: Meta tags and semantic HTML for better search visibility.

## Tech Stack
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (IntersectionObserver, Modal System, Filtering)

## Deployment Instructions
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. For production, ensure the `images/` folder contains the actual high-resolution images or update the URLs in `index.html`.
